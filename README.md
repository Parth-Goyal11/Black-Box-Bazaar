# Trust Assumptions
This currently assumes that a seller will actually timely reveal the information to a seller when the record is purchased, this can be updated to give the seller a specific timeframe. It is also putting trust in a singular centralized admin to regulate decision on disputes, which is a notable factor to address if this were to be scaled.

# Biggest Decision Decision
My biggest design decision was the dispute system that I implemented. The fact that seller credibility is verified off of allowing disputes (where disputing something can get someone money) is a system that allows for credibility in sales and allows to backtrack sales that were not made fairly

# Limitations
Currently runs on a centralized arbiter who is the only one who can settle disputes.
